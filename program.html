PELATIHAN AI ENGINEER BASIC

Program pengenalan Artificial Intelligence dan pembuatan aplikasi Android dengan bantuan AI dan Android Studio, khusus untuk siswa SD Kelas 4–6.

Materi Program

Project 1 — Aplikasi Biodata

Membuat aplikasi profil sederhana berisi nama, foto, kelas, dan hobi.

Project 2 — Aplikasi Kuis

Membuat aplikasi kuis pilihan ganda sederhana dengan sistem skor.

Project 3 — Aplikasi Kalkulator

Membuat aplikasi kalkulator sederhana dengan bantuan prompt AI.

Project 4 — Aplikasi Jadwal Belajar

Membuat aplikasi untuk mencatat jadwal pelajaran atau kegiatan.

Alur Belajar

Setiap pertemuan akan mengajarkan siswa untuk membuat aplikasi dari ide hingga dapat dijalankan di perangkat Android.
